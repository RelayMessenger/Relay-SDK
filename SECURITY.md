# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/relaymessenger/cli/security/advisories/new)
so the report, reproduction details, and any credentials remain private.

Include the affected package and version, impact, reproduction steps, and the
smallest safe proof you can provide. Never include a live Relay Agent Token,
npm token, private conversation, or unrelated user data.

## Supported versions

Security fixes are made against the latest published version of
`@relaymessenger/cli` and `@relaymessenger/vercel-ai`. Older releases may be
superseded instead of patched in place.
